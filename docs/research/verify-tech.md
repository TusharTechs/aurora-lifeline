# Fact-check: Google technology claims

Adversarial fact-check run on 27-28 Sep 2026. Verdicts: CONFIRMED, PARTLY (detail corrected), REFUTED, UNVERIFIED.

| ID | Claim | Verdict | Correction | Evidence | Note |
| --- | --- | --- | --- | --- | --- |
| T1 | A Gemini model with ID "gemini-3.7-flash" was released on 13 Aug 2026; it accepts text, image, video, audio and PDF, has a 1M-token context, and supports function calling, structured output, and Google Search and Maps grounding. | CONFIRMED |  | https://ai.google.dev/gemini-api/docs/models/gemini-3.7-flash | The raw model page shows model code gemini-3.7-flash (Stable). Inputs are text, image, video, audio and PDF, with 1,048,576 input and 65,536 output tokens. Function calling, structured outputs, Search grounding and Maps grounding are all supported. The launch blog (https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-3-7-flash/) is dated 13 Aug 2026 and gives an introductory price of $0.75/$3.75 per 1M input/output tokens until 31 Dec 2026. Two caveats: the Live API is NOT supported on 3.7 Flash, and the models page (https://ai.google.dev/gemini-api/docs/models) now lists gemini-3.8-flash (Sept 2026, same modalities and grounding) as the newest Flash model, with 3.7 labelled 'previous-generation'. |
| T2 | Vertex AI was renamed "Gemini Enterprise Agent Platform" on 22 Apr 2026. | CONFIRMED |  | https://cloud.google.com/blog/products/ai-machine-learning/introducing-gemini-enterprise-agent-platform | Google's Cloud blog calls it 'the evolution of Vertex AI' and says all Vertex AI services will be delivered only through the Agent Platform. The product page title is 'Gemini Enterprise Agent Platform (formerly Vertex AI)'. The announcement was at Next '26: SiliconANGLE dates it 22 Apr 2026, while the Google blog page renders 23 Apr (likely a timezone difference). Strictly, it is a rebrand and consolidation rather than a pure rename. |
| T3 | Google DeepMind's WeatherNext Cyclones / Weather Lab model was published in Nature on 6 Aug 2026 with open-sourced code and weights; cyclone track forecasts are downloadable as CSV and ATCF; real-time data is under experimental terms and historical data is CC-BY-4.0; outputs carry a 'not endorsed by any government meteorological agency' disclaimer. Does it cover the North Indian Ocean? | CONFIRMED |  | https://deepmind.google/blog/weathernext-ai-model-achieves-breakthrough-in-forecasting-cyclones/ | DeepMind blog: Nature paper published 6 Aug 2026 (DOI 10.1038/s41586-026-10953-2), with code and weights open-sourced. GitHub README (https://github.com/google-deepmind/weathernext): code is Apache 2.0 and other materials CC BY 4.0. The README carries the disclaimer 'not been produced in collaboration with nor endorsed by any government meteorological agency'. The Weather Lab guide (https://developers.google.com/weathernext/guides/weatherlab) confirms CSV/ATCF downloads (about 2023 to present), real-time data under the GDM Real-Time Experimental Data Terms, and data at least 1 hour old under CC BY 4.0. North Indian Ocean coverage is UNVERIFIED: the June 2025 DeepMind blog says Weather Lab covers 'all ocean basins', but no page I opened names the Bay of Bengal or Arabian Sea. |
| T4 | WeatherNext 2 (64-member ensemble, 0.25 degree, 6-hourly to 15 days) is available in Earth Engine and BigQuery after an access request taking 5-7 business days. | CONFIRMED |  | https://developers.google.com/earth-engine/datasets/catalog/projects_gcp-public-data-weathernext_assets_weathernext_2_0_0 | The Earth Engine catalog lists 64 members, 0.25 degrees, 00/06/12/18z runs, 6-hour steps to 15 days, and data from 2022 to present; access is via a request form. The access guide (https://developers.google.com/weathernext/guides/access-forecast) says approval typically takes 5-7 business days and one allowlist covers GCS, BigQuery and Earth Engine. Caveat: WeatherNext 3 (Aug 2026; 64 members, hourly runs, 0.05/0.1/0.25 degree) is now the flagship and is 'recommended for all new projects' (https://developers.google.com/weathernext/guides/models). WeatherNext 2 is now legacy. |
| T5 | Gemini API Google Maps grounding is English-only, while Search grounding works in all languages; the Live API supports 24 languages. | PARTLY | The Live API guide says the Live API supports 99 languages, not 24; the Live overview page says 70. The list includes hi, bn, ta, te, mr, gu, kn, ml, or and pa. | https://ai.google.dev/gemini-api/docs/live-guide | Maps grounding: 'currently only supports English language prompts and responses' (https://ai.google.dev/gemini-api/docs/maps-grounding). Search grounding 'works with all available languages' (https://ai.google.dev/gemini-api/docs/google-search). The 24-language figure is wrong or outdated. The Live API runs on Live models such as Gemini 3.8 Live, not on gemini-3.7-flash. |
| T6 | Cloud Speech-to-Text Chirp 3 Indian languages are mostly Preview and hosted only in US/EU regions (not asia-south1). | CONFIRMED |  | https://docs.cloud.google.com/speech-to-text/docs/models/chirp-3 | The raw page lists regional availability as the us and eu multi-regions (GA only), 'with more planned'. hi-IN is GA. bn-IN, ta-IN, te-IN, mr-IN, gu-IN, kn-IN, ml-IN, or-IN, pa-Guru-IN and as-IN are Preview. The page points to the locations API for the latest regions, and the locations doc I opened does not mention asia-south1. |
| T7 | The Google Maps Routes API cannot avoid arbitrary closed roads or polygons (only tolls/highways/ferries/indoor). | PARTLY | RouteModifiers also has avoidTunnels (optional; needs TRAFFIC_AWARE_OPTIMAL; not in computeRouteMatrix), so the list is not only tolls/highways/ferries/indoor. | https://developers.google.com/maps/documentation/routes/reference/rest/v2/RouteModifiers | The main point holds: RouteModifiers has no field for avoiding polygons or specific roads. The route-modifiers guide (https://developers.google.com/maps/documentation/routes/route-modifiers) says modifiers only bias results and may not remove the feature, and that Compute Route Matrix does not support avoidance. Custom routing on your own graph (e.g. OSM) is needed for flooded-road closures. |
| T8 | Google Earth Engine is free only for noncommercial use; operational government use or a SaaS requires a commercial licence. | CONFIRMED |  | https://earthengine.google.com/noncommercial/ | 'Commercial and government operational customers are charged.' Government agencies get free use only if they are from a UN Least Developed Country (India is not one), are an Indigenous Government, or are doing scholarly research. Repeated data products, management or policy web apps, services maintained on an ongoing basis, and even internal R&D or prototyping need a commercial licence. Since 27 Apr 2026, noncommercial projects also have monthly EECU quotas: Community 150, Contributor 1,000, Partner 100,000 EECU-hours (https://developers.google.com/earth-engine/guides/noncommercial_tiers). |
| T9 | Google Flood Hub added urban flash-flood forecasts up to 24 h ahead in March 2026 on a ~20 km grid, and has a flood forecasting API. | CONFIRMED |  | https://research.google/blog/protecting-cities-with-ai-driven-flash-flood-forecasting/ | The Google Research blog (12 Mar 2026) gives up to 24 h lead time, 20x20 km resolution, and urban areas above 100 people per sq km; the Flood Hub help page (https://support.google.com/flood-hub/answer/16811681) matches. The Flood Forecasting API (https://developers.google.com/flood-forecasting/rest/v1/flashFloods/search) needs a waitlist, is free and CC BY 4.0. Besides riverine floodStatus/gauges, it has a v1 flashFloods:search endpoint that filters by country code. Flash-flood coverage of specific Indian cities was not checked. |
| T10 | Google's Air View+ (Nov 2024) runs sensors in 150+ Indian cities, and the Google Air Quality API covers India with the CPCB index at 500 m resolution and 96-hour forecasts. | CONFIRMED |  | https://blog.google/intl/en-in/company-news/using-googles-ai-and-local-ecosystem-to-generate-actionable-air-quality-insights-in-india-with-air-view/ | The Google India blog (20 Nov 2024) says sensors are deployed 'across more than 150 Indian cities', with partners Aurassure, Respirer Living Sciences, IIT Delhi and IIT Hyderabad. The Air Quality API overview (https://developers.google.com/maps/documentation/air-quality/overview) gives 500x500 m resolution, forecasts up to 96 h and 30 days of history. The coverage page (https://developers.google.com/maps/documentation/air-quality/coverage) lists India with default local AQI ind_cpcb. |
